## 发言规范

1. 事实性断言必须附 `文件:行号`；推测显式标注。
2. 已核实事实进入 `decisions.md` 的事实表（`F<n>`），双方不重复验证。
3. 改变立场时新增发言并写明「撤回 / 收回 / 维持」，不改历史发言。
4. author 每次修订必须声明引入的新字段、新不变量、新用户承诺；下一轮只审该 delta。
5. author 需评估收益与成本，**拒绝是预期行为**。
6. `僵持` 是合法终态，交人类裁决，不为收敛而单方让步。
7. 收敛记账（写 `decisions.md`、`git mv` 归档、更新 `MAILBOX.md`）由复核方在收敛当轮执行。
